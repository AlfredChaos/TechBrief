# TechBrief MVP 验收清单（Web + Admin）

更新时间：2026-06-03

## 1. 验收目标

- [ ] OpenAI 与 Anthropic 各选 5 条历史公开内容回放处理，其中包含文章以及来自更多公开视频平台的视频资料，10/10 成功生成可审核中文内容
- [ ] 标题层级、代码块、主要链接不丢失（抽样结构保真 >= 98%）
- [ ] 新内容发现：在模拟新增或实际新增情况下，系统能在调度周期内发现并入库
- [ ] 去重：同一内容重复巡检不会重复创建站内内容记录
- [ ] 可追溯：任一失败能看到失败阶段与错误摘要；能从失败点重试并成功
- [ ] 公开站点可访问：首页、列表页、详情页可正常浏览
- [ ] 邮件订阅链路可用：用户可完成订阅、退订，并收到每日汇总邮件
- [ ] 后台管理可用：可查看订阅者列表、文章及译文列表、每日工作流执行情况
- [ ] 后台手动发布可用：支持手动录入其他文章，并支持手动创建微信公众号草稿

## 2. P0 功能清单（逐项验收）

### 2.1 内容发现与去重

- [ ] 支持 OpenAI 与 Anthropic 两个来源
- [ ] 支持文章和视频两类公开内容发现
- [ ] 视频来源支持更多公开视频平台
- [ ] RSS 优先；无 RSS 时轮询列表页
- [ ] 支持 ETag / Last-Modified 的条件请求
- [ ] canonical_url / source_id 去重生效
- [ ] 去重键：`dedupe_key = sha256(source + content_type + canonical_url_or_source_id)`
- [ ] 已处理内容不重复入队

### 2.2 抓取与落库

- [ ] 抓取详情页 HTML 成功，并保存原始内容快照
- [ ] 视频资料保存标题、来源链接、发布时间、简介、字幕或文本来源状态
- [ ] 视频无字幕时可提取音频并生成转录文字稿
- [ ] 原始内容可用于追溯与重跑

### 2.3 正文 / 字幕抽取（结构化）

- [ ] 文章抽取结构单元：H1-H4、P、UL/OL、BLOCKQUOTE、CODE_BLOCK、IMAGE、HR
- [ ] 保留原文链接（URL 不变）
- [ ] 解析元信息：title、author / speaker、published_at、cover_image、source_name
- [ ] 视频内容在有字幕时可抽取字幕文本；无字幕时可生成转录文字稿
- [ ] 无字幕视频可基于转录稿生成深度研究报告

### 2.4 全文翻译

- [ ] code block / inline code 原样保留
- [ ] 链接 URL 不翻译；链接文本可翻译
- [ ] 段落与标题层级保持一致
- [ ] 支持 glossary（YAML / JSON）术语表并执行一致性替换
- [ ] 最小质量检查：标题数量与层级差异、code block 数量一致、关键链接数量一致

### 2.5 Web 展示与发布

- [ ] 公开首页可展示最新内容
- [ ] 列表页支持按来源、内容类型、发布时间筛选
- [ ] 详情页展示中文内容、来源信息、原文链接、免责声明
- [ ] 后台可将待审核内容手动发布到公开站点
- [ ] 文末固定区块模板正确出现

### 2.6 邮箱订阅

- [ ] 支持邮箱订阅
- [ ] 支持退订
- [ ] 记录订阅状态、订阅时间、退订状态
- [ ] 新内容发布后按每日汇总策略发送邮件
- [ ] 邮件发送结果可追踪，失败可重发

### 2.7 后台管理

- [ ] 仪表盘可查看当日新增、已发布、失败、订阅新增、成功率
- [ ] 订阅者列表页可查看邮箱、状态、订阅时间
- [ ] 内容列表页可查看原文、译文、状态、来源、内容类型
- [ ] 每日工作流执行页可查看 discover / fetch / extract / translate / publish / notify 状态
- [ ] 支持从失败点重试
- [ ] 支持手动录入其他文章链接并自动抓取
- [ ] 支持纯手工录入标题、摘要、正文和来源信息

### 2.8 微信公众号手动发布页

- [ ] 后台存在独立的手动发布页
- [ ] 可基于站内已发布内容生成公众号草稿，并复用封面、摘要和作者信息
- [ ] 可手动录入标题、作者、正文后生成公众号草稿
- [ ] 记录 `wechat_draft_id`、错误码与响应摘要
- [ ] 失败后支持重试
